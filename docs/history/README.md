# About these pages

These are the development plans of CFD-craft as they were written, kept
unchanged apart from link and fence-label updates. Each plan states its scope and its gates
before the work; the results are in the [evidence records](../evidence/README.md),
and the current state of the code is in the [guide](../guide/README.md) and the
[developer pages](../developer/README.md). A plan is not a description of what
the code does now.

The dates are the ones each plan states. Plans without a date name the code
revision they started from.
