# Model cards

- [Flow](flow.md): pressure projection, laminar and neutral k–epsilon package.
- [Transport](transport.md): conservative gas balance, sources, receptors and response matrices.
- [Evidence and restart](../result-contract.md): the meaning and provenance of a result.
- [OpenFOAM backend](openfoam-backend.md): external execution, numerical comparison and preliminary experimental assessment.

Each card states a supported scope, discretization and verification evidence. An implemented equation and a converged solution do not establish experimental validation.
